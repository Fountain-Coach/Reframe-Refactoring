# Reframe publication boundary

The Governance book is a public projection of reviewed doctrine and evidence. It is not a mirror of the private
Reframe runtime repository.

Public material may include reviewed governance chapters, sanitized command and capability descriptions, named release
boundaries, AX/VRT evidence, and provenance. It must not include runtime source, private dependencies, private
fixtures, manuscript material, FountainStore records, credentials, deployment secrets, or unreleased machinery.

A private implementation repository must never be presented as a public source. Public links must either resolve for
their intended audience or state the access boundary plainly. Governance explains why the boundary exists; it does not
override runtime state, capability registries, live acceptance, or release manifests.

Every publication change requires source provenance, sanitization review, link/metadata checks, accessibility and visual
acceptance where the surface changes, and a rollback-aware deployment record. This policy is not a licence to publish
private data or a legal opinion.

See [Chapter 44](docs/44-publication-and-source-policy.md) for the governing doctrine and
[SOURCE.md](SOURCE.md) for repository synchronization provenance.
